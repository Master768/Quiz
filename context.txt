Create a modern, production-ready quiz web application using the Excel sheet I provide as the database source.

The Excel sheet contains:
- Question text
- Multiple choice options
- Correct answer
- Points/marks for each question

Your task is to build a fully functional, visually stunning, responsive quiz platform with premium UI/UX design.

==================================================
IMPORTANT QUIZ BEHAVIOR
==================================================

- ALL questions must appear on a SINGLE PAGE.
- Do NOT create one-question-per-page navigation.
- Users should be able to scroll through all questions smoothly.

When a user selects an option:
- Instantly validate the answer in real time.
- If the selected answer is CORRECT:
  • Highlight the option in GREEN
  • Show a smooth success animation
  • Display “Correct Answer” feedback

- If the selected answer is WRONG:
  • Highlight the selected option in RED
  • Automatically highlight the correct answer in GREEN
  • Display “Wrong Answer” feedback

- Disable changing answers after selection (optional toggle).
- Add smooth animations and transitions for answer feedback.
- Provide satisfying interaction effects similar to premium quiz apps.

CORE FEATURES

1. Excel Upload & Parsing
- Allow admin/user to upload .xlsx or .csv files
- Automatically parse:

- Smooth scrolling navigation
- Animated option selection states
- Real-time answer validation
- Instant feedback system
- Auto score calculation

3. Scoring System
- Calculate score instantly
- Track:
  • Correct answers
  • Wrong answers
  • Total score
  • Percentage
- Live score updates while answering

4. Results Section
- Final performance dashboard
- Circular progress charts
- Correct vs wrong analytics
- Motivational feedback
- Review answers section
